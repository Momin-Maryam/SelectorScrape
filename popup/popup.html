How to use SelectorScrape

Basic flow:

  1. Add a field: type a name + CSS selector, choose a type, click Add Field — or click the crosshair icon next to any selector box and click directly on the element you want on the page (press Esc anytime to cancel picking without selecting anything — your cursor turns into a crosshair while picking is active).
  2. (Optional) Expand Pagination to set a Next Page Selector + max pages, for scraping multiple pages automatically.
  3. (Optional) Expand Detail Page / Nested Scraping to set a Detail Link Selector + child fields, to pull extra data from each item's detail page.
  4. Click Extract Data (current page only), Scrape All Pages (pagination only, no detail pages), or Scrape With Detail Pages (visits each item's detail page — and if you've also filled in a Next Page Selector, it walks every listing page too, combining both).
  5. Export your results as CSV, JSON, or Excel — or save your whole field setup as a Sitemap (JSON) to reuse later.

What each button does:

  • Crosshair icon — click, then click any element on the page to auto-fill that specific selector box
  • Add Field / Add Child Field — saves the field you just filled in
  • Scrape All Pages — extracts data, then follows your "next page" link automatically
  • Scrape With Detail Pages — visits each item's detail page and merges the extra data in
  • Export Sitemap / Import Sitemap — save or reload your whole field configuration

Important: after reloading the extension in chrome://extensions, you must hard-refresh the page tab (F5) before using the extension there again — otherwise you'll see a "could not reach the page" error.

During a multi-page or nested scrape, the popup will close automatically as the page navigates — that's expected. Just reopen the popup after a few seconds to check progress.
